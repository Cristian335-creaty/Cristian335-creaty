## Proyectos destacados

ci-cd-quality-pipeline-java: pipeline de integracion continua en Java (Maven) con GitHub Actions e integracion de analisis de seguridad estatico (SAST) usando Horusec.

kubernetes-canary-release-demo: demostracion de despliegue canary sobre Kubernetes (Minikube) usando el ingress controller de NGINX, con control de trafico progresivo entre versiones.

university-student-management-system: aplicacion ASP.NET Core MVC para la gestion de estudiantes universitarios, con autenticacion de usuarios (ASP.NET Identity) y persistencia en base de datos con Entity Framework.

rag-chatbot-fastapi: chatbot con arquitectura RAG (busqueda semantica + generacion de respuestas) construido con FastAPI y Sentence Transformers.

inventory-sales-rest-api: API REST en Node.js y Express para la gestion de inventario y ventas, con Sequelize para el acceso a base de datos.

call-transcription-api: API en Python que transcribe llamadas de audio con Whisper y permite buscar por contenido y tono dentro de las transcripciones.
