## Stack principal

Java, C# (.NET), Python, JavaScript / Node.js, Docker, Kubernetes, GitHub Actions, SQL Server, Firebase.

## Proyectos destacados

rag-chatbot-fastapi: chatbot con arquitectura RAG (busqueda semantica + generacion de respuestas) construido con FastAPI y Sentence Transformers.

call-transcription-api: API en Python que transcribe llamadas de audio con Whisper y permite buscar por contenido y tono dentro de las transcripciones.

everwood-faq-cloud-platform: plataforma cloud para carga y gestion de archivos con generacion automatica de preguntas frecuentes, desplegada en Firebase.

ci-cd-quality-pipeline-java: pipeline de integracion continua en Java con analisis de seguridad estatico (SAST) usando Horusec.

kubernetes-canary-release-demo: demostracion de despliegue canary sobre Kubernetes con control de trafico progresivo entre versiones.

university-student-management-system: aplicacion ASP.NET Core MVC para la gestion de estudiantes con autenticacion de usuarios.
